01 · 개념 · 교과서 131~132쪽

오차만으로는 부족하다

지난번에 기온이랑 풍속으로 미세먼지 예측하는 모델, 계수까지 다 구했잖아.
어, 오차 제곱합이 최소가 되는 값으로 구했지.
근데 그 오차가 작은 건지 큰 건지, 기준이 없으면 알 수가 없지 않아?
듣고 보니 그러네. "얼마나 작아야 좋은 거야?"라는 질문엔 아직 답을 못 하겠어.

평균제곱오차(MSE)는 원래 데이터와 같은 단위로 움직이기 때문에, 서로 다른 데이터에 대해 구한 값을 곧바로 비교하기 어렵습니다. 그래서 회귀 모델이 데이터를 얼마나 잘 설명하는지를 나타내는 또 다른 지표가 필요합니다.

📖 교과서 원문『데이터 과학』 132쪽

"결정 계수(R² score: R-squared score)는 회귀 모델이 실제 데이터와 얼마나 유사하게 예측하고 구체적으로 설명하는지를 나타낸다."

결정계수는 다음과 같이 구합니다. 분자는 내가 만든 모델의 오차제곱합(SSE)이고, 분모는 "평균으로만 예측했다면 생겼을" 오차제곱합(SST)입니다.

R²=1− SSESST
SSE실젯값과 내 모델의 예측값 차이를 제곱해 더한 값. 이미 배운 오차제곱합입니다.
SST실젯값과 평균값의 차이를 제곱해 더한 값. "모델 없이 평균만 찍었을 때"의 기준점입니다.

SST는 데이터 자체가 가진 값이라 내 모델과 상관없이 항상 고정되어 있습니다. 반면 SSE는 내가 만든 모델(계수)에 따라 달라집니다. 그래서 결정계수는 이렇게 해석합니다.

  • 1에 가까울수록 — 모델이 데이터를 잘 설명한다.
  • 0에 가까울수록 — 평균으로 찍은 것과 큰 차이가 없다.
  • 0보다 작을 수도 있다 — 모델이 평균보다도 못한, 오히려 나쁜 예측을 한다는 뜻이다.

02 · 실습 · 교과서 132~133쪽

같은 데이터로 채점하면 벌어지는 일

지금까지 실험에서는 계수를 구할 때 썼던 데이터로 오차와 결정계수를 다시 계산했습니다. 이미 풀어 본 문제로 시험을 보면 항상 점수가 잘 나오는 것처럼, 모델도 학습에 쓴 데이터에서는 실제보다 좋아 보일 수 있습니다.

그래서 데이터를 두 부분으로 나눕니다. 계수를 구하는 데 쓰는 훈련 데이터와, 그 계수가 처음 보는 데이터에도 통하는지 확인하는 평가 데이터입니다.

"과대적합은 훈련 데이터에 지나치게 맞춰져 새로운 데이터에 대한 예측력이 떨어지는 것을 말한다."

03 · 실험 · 교과서 133쪽

모델이 너무 열심히 외우면 생기는 일 — 과대적합

훈련 성능과 평가 성능의 차이가 아주 크게 벌어지는 경우가 있습니다. 이를 과대적합이라고 하며, 특히 두 가지 상황에서 잘 나타납니다.

① 모델이 너무 복잡할 때 — 다항 회귀의 차수

지난 시간에 배운 다항 회귀에서, 고차항을 계속 늘리면 무슨 일이 벌어질까요? 이번에는 기온 하나만으로 미세먼지를 예측하는 다항 회귀를 만들고, 차수를 슬라이더로 직접 올려 봅시다. (훈련·평가 데이터는 위와 같은 96개월/24개월입니다.)

차수를 높여 보면 훈련 성능(청록)은 계속 좋아지는 것처럼 보이지만, 평가 성능(주황)은 어느 지점을 지나면 오히려 나빠지기 시작합니다. 그 지점을 넘어서도 계속 차수를 올리는 것이 바로 과대적합입니다.

교과서는 이런 과대적합을 막는 방법으로 규제(regularization)를 짧게 언급합니다. 규제는 회귀 계수가 너무 커지지 않도록 억누르는 방법인데, 자세한 계산은 이 절의 범위를 벗어나므로 다루지 않습니다.

② 데이터 개수가 너무 적을 때

복잡한 모델이 아니어도, 데이터 개수 자체가 너무 적으면 과대적합이 일어날 수 있습니다. 훈련에 사용하는 개월 수를 슬라이더로 줄여 가며, 훈련 결정계수와 평가 결정계수의 차이가 어떻게 달라지는지 확인해 보세요. (기온·풍속을 함께 쓰는 모델이며, 평가 데이터는 항상 같은 24개월입니다.)

    main.py
    import streamlit as st
import pandas as pd
import plotly.express as px
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

DATA_URL = "https://raw.githubusercontent.com/keep-growing-park/ds-data-modeling/main/dataset/seoul_air_quality_2015_2024.csv"

st.title("서울 미세먼지 모델 평가")

df = pd.read_csv(DATA_URL)
X = df[["avg_temp_c", "avg_wind_speed_ms"]]
y = df["pm10_ug_m3"]

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, shuffle=False
)

model = LinearRegression()
model.fit(X_train, y_train)

pred_train = model.predict(X_train)
pred_test = model.predict(X_test)

result = pd.DataFrame({
    "MSE": [mean_squared_error(y_train, pred_train), mean_squared_error(y_test, pred_test)],
    "R2": [r2_score(y_train, pred_train), r2_score(y_test, pred_test)],
}, index=["훈련 데이터", "평가 데이터"])
st.dataframe(result)

df_plot = pd.concat([
    pd.DataFrame({"실젯값": y_train, "예측값": pred_train, "구분": "훈련"}),
    pd.DataFrame({"실젯값": y_test, "예측값": pred_test, "구분": "평가"}),
])
fig = px.scatter(df_plot, x="실젯값", y="예측값", color="구분")
st.plotly_chart(fig, width="stretch")

06 · 정리

핵심 정리

01

결정계수(R²)는 모델이 데이터를 얼마나 잘 설명하는지를 나타내며, 1에 가까울수록 좋고 0보다 작을 수도 있다.

02

학습에 사용한 데이터로 모델을 다시 평가하면 성능이 부풀려질 수 있어, 훈련 데이터와 평가 데이터를 나누어야 한다.

03

모델이 너무 복잡하거나 데이터가 너무 적으면, 훈련 성능은 좋은데 평가 성능이 나빠지는 과대적합이 발생할 수 있다.

04

여러 모델의 평가 지표를 비교해 더 나은 모델을 선택할 수 있다.
