01 · 개념 · 교과서 118~119쪽

선형 회귀란 무엇일까?

두 친구의 대화를 먼저 살펴봅시다. 우리는 이미 일상에서 "회귀적으로" 생각하고 있었을지도 몰라요.

어제 그 무협 웹소설 정주행했는데 50화까지 보는 데 3시간 좀 안 걸렸어.
오 꽤 봤네. 오늘도 이어서 볼 거야?
어. 근데 오늘은 80화까지 볼 건데, 그럼 시간이 얼마나 더 걸릴까?
화수가 더 많으니까 오늘이 어제보다는 오래 걸리지 않을까?

친구는 화수가 늘어나면 정주행 시간도 늘어날 것이라 예측했습니다. 이렇게 두 속성 사이에 선 모양의 관계가 있다고 가정하고, 데이터를 가장 잘 대표하는 선을 찾는 분석 방법을 교과서는 다음과 같이 정의합니다.

📖 교과서 원문『데이터 과학』 119쪽

"선형 회귀는 두 가지 이상의 속성 사이에 선 모양의 관계가 있다고 가정하고 데이터를 가장 잘 대표하는 선을 찾는 분석 방법이다."

여기서 우리가 맞히고 싶은 값(정주행 시간)이 종속 변수이고, 맞히는 데 참고하는 값(화수)이 독립 변수입니다. 이 둘을 가장 잘 이어 주는 선을 회귀선이라고 부르고, 독립 변수를 하나만 쓰는 경우를 단순 선형 회귀라고 합니다.

y=ax+b
a — 가중치 (기울기)x가 1 늘어날 때마다 y가 얼마씩 달라지는지를 나타내는 숫자로, 두 값이 얼마나 밀접하게 붙어 움직이는지를 보여줍니다.
b — 편향 (절편)x를 전혀 반영하지 않았을 때, 즉 x=0일 때 남는 기본값입니다. x가 무엇이든 매번 똑같이 얹히는 부분이라고 생각하면 됩니다.

a와 b처럼 회귀 모델에서 구하고자 하는 값을 회귀 계수라고 합니다. 최적의 a, b를 구하면 회귀선이 완성됩니다.

‘회귀’라는 용어의 유래. 영국의 통계학자 프랜시스 골턴(Francis Galton)이 바로 이 이름을 붙인 사람입니다. 그는 여러 세대에 걸쳐 부모와 자녀의 키를 비교하다가 재미있는 패턴을 발견했는데, 키가 유난히 크거나 작은 부모에게서 태어난 아이일수록 오히려 평균 키에 더 가깝게 태어나더라는 것이었습니다. 이렇게 극단적인 값이 평균 쪽으로 '되돌아가는' 모습에서 회귀라는 이름이 나왔습니다.
🔭 역사 속 회귀 분석 — 케플러와 화성 궤도

16세기 말, 덴마크 천문학자 튀코 브라헤는 망원경도 없이 20년 가까이 행성의 위치를 극도로 정밀하게 관측한 기록을 남겼습니다. 그가 세상을 떠난 뒤 이 자료를 물려받은 요하네스 케플러는, 당시 모두가 당연하게 여기던 "행성은 원 궤도로 돈다"는 가정으로 화성의 궤도를 계산했습니다.

그런데 실제 관측값과 원 궤도 모델 사이에 약 8분(0.13°)의 오차가 계속 남았습니다. 아주 작은 차이였지만, 브라헤의 관측이 그보다 훨씬 정밀하다는 것을 알던 케플러는 이 오차를 측정 실수가 아니라 모델 자체가 틀렸다는 신호로 받아들였습니다. 원 궤도 가정을 버리고 수년간 계산을 반복한 끝에, 타원 궤도로 가정하면 데이터에 훨씬 잘 들어맞는다는 것을 발견했습니다. 이것이 1609년에 발표된 케플러 제1법칙입니다. 데이터에 가장 잘 맞는 관계를 끝까지 찾아낸, 회귀 분석의 정신을 보여주는 사례입니다.

03 · 두 가지 회귀 모델 · 교과서 120~127쪽

최적의 선, 어떻게 찾을까?

최적의 가중치와 편향을 구하는 방법에는 두 가지가 있습니다. 하나는 수식을 풀어 한 번에 계산하는 방법, 다른 하나는 컴퓨터가 조금씩 값을 보정해 나가는 방법입니다.

통계적 회귀 모델

수식을 풀어 한 번에 계산

오차를 나타내는 식을 세운 뒤, 그 식을 풀어 곧바로 정답을 얻어냅니다. 독립 변수가 하나뿐이라면 아래 공식 하나로 계산이 끝납니다.

a = Σ(x−x̄)(y−ȳ) / Σ(x−x̄)²
b = ȳ − a·x̄

인공지능 이전부터 쓰여온, 통계학에 기반한 방법입니다. (120~121쪽)

기계학습 기반 회귀 모델

조금씩 보정하며 다가가기

데이터를 하나씩 살펴보면서 예측이 크게 빗나가면 계수를 큼직하게, 거의 맞으면 아주 조금만 바꾸는 식으로 계속 손봐 나갑니다. 이 방법을 경사 하강법이라 부릅니다.

회귀 계수를 바꿔가며 평균제곱오차를 그래프로 그리면 U자 모양이 나타나는데, 그 바닥을 향해 한 걸음씩 내려가는 셈입니다. (124~125쪽)

🖐️ 손으로 확인해보기 — 공식에 값 대입하기 (교과서 121쪽과 같은 활동, 선택)

시간이 부족하면 직접 계산하지 않아도 됩니다. 아래 단계를 하나씩 눌러 과정만 확인해도 충분합니다. 실험 절에서 쓴 데이터 (20,70), (35,120), (50,165), (65,210), (80,255)를 그대로 공식에 넣어 계산해 봅니다.

1단계 — 평균 구하기

x̄ = (20+35+50+65+80) ÷ 5 = 50

ȳ = (70+120+165+210+255) ÷ 5 = 164

2단계 — 편차와 편차의 곱 구하기

각 점에서 x−x̄와 y−ȳ를 구하고, 둘을 곱합니다.

xyx−x̄y−ȳ(x−x̄)(y−ȳ)(x−x̄)²
2070−30−942820900
35120−15−44660225
501650100

3단계 — 각 열의 합 구하기

Σ(x−x̄)(y−ȳ) = 2820+660+0+690+2730 = 6900

Σ(x−x̄)² = 900+225+0+225+900 = 2250

4단계 — a, b 계산하고 확인하기

a = 6900 ÷ 2250 ≈ 3.07

b = 164 − 3.07 × 50 ≈ 10.5

즉 이 데이터에 가장 잘 맞는 회귀선은 y ≈ 3.07x + 10.5 입니다. 실험 절에서 🏆 최적의 회귀선 비교해 보기 버튼을 눌렀을 때 그래프에 나온 식과 같은지 확인해 보세요. 버튼 하나가 순식간에 해 준 계산을, 우리는 방금 손으로 따라가 본 것입니다.

통계적 회귀 모델기계학습 기반 회귀 모델
계산 방식미분과 평균을 이용한 공식에 데이터를 대입해 최적의 계수를 단번에 계산해 낸다.예측과 실제의 차이를 관찰하면서, 그 차이가 줄어드는 방향으로 계수를 여러 번에 걸쳐 갱신해 나간다.
주로 쓰는 목적두 속성이 서로 얼마나, 어떤 방향으로 영향을 주고받는지 설명하려는 연구에 알맞다.관계를 설명하는 데 그치지 않고, 아직 보지 못한 새로운 입력값을 알아맞히려는 목적에 주로 쓰인다.
알맞은 상황두 변수의 관계가 대체로 하나의 직선이나 평면으로 설명될 만큼 단순한 경우데이터의 양이 많고, 반복 계산을 빠르게 처리할 컴퓨팅 자원이 갖춰져 있는 경우

교과서 표 Ⅲ-2 (126~127쪽)의 비교 내용을 제 표현으로 다시 정리했습니다.

회귀선도 결국 하나의 '모델'입니다. 지하철 노선도를 떠올려 보세요. 실제 지형·거리와는 많이 다르게 그려져 있지만, "어느 역에서 어느 역으로 갈아타야 하는가"라는 목적에는 오히려 그게 더 쓸모 있습니다. 회귀선도 마찬가지입니다. 그날의 우연한 사정, 사람마다 다른 세세한 차이는 다 걷어내고, "화수가 늘면 정주행 시간이 대략 이만큼 늘어난다"는 핵심 관계만 남긴 단순화된 지도입니다. 통계학자 조지 박스는 이를 두고 "모든 모델은 틀렸다. 다만 일부는 쓸모가 있다"는 말을 남겼습니다. 완벽한 예측이 아니라, 목적에 맞게 얼마나 쓸모 있는가가 회귀 모델을 판단하는 기준입니다.
04 · 학습 기간과 예측의 한계

같은 데이터, 다른 결론 — 학습 기간이 왜 중요할까

회귀선은 학습에 사용한 데이터의 범위 안에서만 믿을 만합니다. 그 범위를 벗어난 값을 추정하는 것을 외삽이라고 하는데, 같은 데이터라도 어느 기간을 학습에 쓰느냐에 따라 기울기와 예측값이 크게 달라질 수 있습니다. 실제 병역판정검사 자료로 확인해 봅시다.

    main.py
    import streamlit as st
import pandas as pd
import numpy as np
import plotly.express as px

DATA_URL = "https://raw.githubusercontent.com/keep-growing-park/ds-data-modeling/main/dataset/military_service_bmi.csv"

st.title("병역판정검사 체중 추이 예측기")

df = pd.read_csv(DATA_URL)
col = "과체중+비만_합계(%)"

a, b = np.polyfit(df["연도"], df[col], 1)
pred = a * df["연도"] + b
ss_res = float(((df[col] - pred) ** 2).sum())
ss_tot = float(((df[col] - df[col].mean()) ** 2).sum())
r2 = 1 - ss_res / ss_tot

fig = px.scatter(df, x="연도", y=col)
fig.add_scatter(x=df["연도"], y=pred, mode="lines", name="회귀 직선")
st.plotly_chart(fig, width="stretch")
st.caption(f"학습에 사용한 연도: {df['연도'].min()}~{df['연도'].max()}년 · 결정계수 R² = {r2:.3f}")

year = st.slider("연도를 고르세요", 2008, 2035, 2026)
st.metric(f"{year}년 예상 과체중+비만 비율", f"{a * year + b:.1f}%")
if year > df["연도"].max():
    st.info("학습 범위 밖의 외삽값입니다. 실제 미래 수치를 보장하지 않습니다.")

핵심 정리

01

선형 회귀는 y = ax + b라는 식으로 데이터의 흐름을 가장 잘 담아내는 선을 찾는 방법이며, 독립 변수를 하나만 쓰면 단순 선형 회귀라고 한다.

02

실제 값과 모델의 예측이 벌어진 정도인 오차를 제곱해 합한 값이 작을수록 더 믿을 만한 회귀선이다.

03

통계적 회귀 모델은 수식을 풀어 회귀 계수를 한 번에 계산하고, 기계학습 기반 회귀 모델은 경사 하강법으로 계수를 조금씩 보정해 최적값에 접근한다.
