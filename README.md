# 데이터 모델링과 평가

고등학교 2학년 데이터 과학 수업용 온라인 콘텐츠입니다. 「Ⅲ. 데이터 모델링과 평가」 단원을 학생이 교과서와 나란히 펴 놓고 볼 수 있도록 만들었습니다. (Ⅲ-1. 데이터 모델과 모델링은 학습지·교과서로 진행하며 이 사이트에는 없습니다.)

`index.html`이 전체 목차이고, 세부 주제마다 별도 페이지로 이동합니다.

파일명은 `{단원 번호}-{꼭지 순서}-영문슬러그.html` 형식입니다 (예: 회귀 분석은 2단원이므로 그 첫 번째 꼭지는 `2-1-linear-regression.html`).

## 선형 회귀 페이지 구성
- 개념 설명 + 교과서 원문 인용(쪽수 포함)
- 가중치·편향을 직접 조절하며 오차를 비교하는 인터랙티브 실험
- 통계적 회귀 모델 vs 기계학습 기반 회귀 모델 비교, 경사 하강법 시뮬레이터
- 학습 기간에 따라 달라지는 예측(외삽 위험) — 실제 병역판정검사 데이터 사용
- 파이썬을 직접 타이핑하는 대신, AI에게 프롬프트로 요청해 스트림릿 앱을 만드는 바이브 코딩 실습

`dataset/` 폴더에 실습용 CSV 데이터를 둡니다.

빌드 도구 없는 정적 페이지들입니다. 저장소 설정에서 GitHub Pages를 켜면(Settings → Pages → Branch: 배포할 브랜치 선택) 별도 빌드 없이 바로 온라인으로 열람할 수 있습니다.
