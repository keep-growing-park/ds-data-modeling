01 · 개념 · 교과서 128~129쪽

화수만으로는 부족하다

어제는 50화를 3시간 만에 봤는데, 오늘은 30화만 봤는데도 3시간 가까이 걸렸어.
어? 화수는 오늘이 더 적은데 왜 시간은 비슷해?
아, 오늘은 알림이 계속 와서 확인하느라 자주 멈췄거든.
그럼 화수 말고 딴짓한 횟수도 정주행 시간에 영향을 주는 거네.

화수 하나만으로는 정주행 시간이 다 설명되지 않습니다. 딴짓(알림 확인) 횟수처럼 영향을 주는 다른 요인이 있을 수 있습니다. 이렇게 종속 변수에 영향을 주는 요인이 여러 개일 때, 독립 변수를 두 개 이상 사용하는 회귀 분석을 교과서는 다음과 같이 정의합니다.

📖 교과서 원문『데이터 과학』 128쪽

"다중 선형 회귀(multiple linear regression)는 영향을 미치는 요인이 여러 개인 경우에 종속 변수를 설명하기 위해 여러 개의 독립 변수를 이용하는 회귀 분석이다."

독립 변수가 하나면 회귀식은 평면 위의 직선이었습니다. 독립 변수가 두 개가 되면, 이제 예측값은 3차원 공간에서 하나의 평면이 됩니다. 독립 변수가 더 늘어나면 그보다 높은 차원의 초평면이 되지만, 원리는 같습니다.

y=a₁x₁+a₂x₂+b
a₁, a₂ — 회귀 계수각 독립 변수가 종속 변수에 미치는 영향력의 크기입니다. 독립 변수마다 하나씩 있습니다.
b — 회귀 계수(편향)모든 독립 변수가 0일 때 남는 기본값으로, a₁·a₂와 마찬가지로 회귀 계수의 하나입니다. 단순 회귀에서 편향이라 불렀던 것과 뜻이 같습니다.

간단한 두 식을 하나로 합쳐 보기

회귀 계수를 실제로 구하는 계산은 뒤에서 앱으로 확인하기로 하고, 먼저 아이디어만 느껴 봅시다. 화수(x₁)만 고려했을 때와 딴짓 횟수(x₂)만 고려했을 때 각각 다음과 같은 간단한 회귀식을 얻었다고 가정해 보겠습니다.

y = 3x₁ + 10 (화수만 고려)
y = 4x₂ + 5 (딴짓 횟수만 고려)

두 식의 양변을 각각 더하면 2y = 3x₁ + 4x₂ + 15가 되고, 양변을 2로 나누면 다음과 같습니다.

y = 1.5x₁ + 2x₂ + 7.5

💡 실제 다중 회귀 계수는 이렇게 단순히 더해서 구하지 않고, 여러 독립 변수를 동시에 고려하는 계산으로 구합니다. 여기서는 "여러 식을 하나로 합친다"는 감각만 잡아 보는 것입니다.

독립 변수가 셋 이상이어도 원리는 같습니다. 일반화하면 다음과 같으며, a₁, a₂, ..., aₙ과 b가 이번에도 회귀 계수입니다.

y = a₁x₁ + a₂x₂ + ... + aₙxₙ + b
02 · 실험 · 실제 데이터로 확인하기

직관 대 실제 — 계수를 맞혀 보자

이번에는 실제 통계로 실험합니다. 서울의 평균기온과 평균풍속으로 미세먼지(PM10) 농도를 예측해 봅시다. 슬라이더로 두 계수를 직접 맞혀 보고, 실제 정답과 비교해 보세요.

오늘 쓰는 데이터. 국가통계포털(KOSIS)의 서울 2015~2024년 월별 평균기온·평균풍속(기상청 「기상관측통계」)과 미세먼지 PM10(기후에너지환경부 「대기오염도현황」) 자료를 합친 120개월치 데이터입니다(dataset/seoul_air_quality_2015_2024.csv, 미리 보기 ↗).

표시된 점은 전체 120개월 중 40개(3개월 간격) 표본이며, 평균제곱오차 계산에는 120개월 전체를 사용합니다.

a₁ 기온 계수0.00
a₂ 풍속 계수0.0
PM10 = 0.00·기온 + 0.0·풍속 + –
평균제곱오차
–

편향 b는 두 계수에 맞춰 자동으로 계산됩니다. 기울어진 청록 면이 지금 계수로 만든 예측 평면이고, 주황 점은 실제 관측값입니다. 점과 면 사이 세로선(오차)이 짧을수록 예측이 정확합니다.

03 · 살짝 미리보기 · 교과서 130~131쪽

곡선도 다중 회귀로 풀 수 있다면?

지금까지는 독립 변수가 그대로(x₁, x₂) 회귀식에 들어갔습니다. 그런데 x²처럼 고차항이 필요한 경우는 어떻게 할까요? 고차항을 새로운 독립 변수로 보면, 지금 배운 다중 회귀 방식을 그대로 적용할 수 있습니다. 이런 회귀를 다항 회귀라고 합니다.

y = a₁x₁ + a₂x₁² + b
↓ x₁² 을 새로운 변수 z로 보면
y = a₁x₁ + a₂z + b

고차항을 많이 쓸수록 훈련 데이터에는 더 잘 들어맞는 곡선을 그릴 수 있지만, 그만큼 과대적합의 위험도 커집니다. 이 부분은 다음 절 "회귀 모델 평가"에서 직접 확인해 봅니다.

🤔 어? 바람이 셀수록 미세먼지가 는다고? 위 실험에서 "정답 확인하기"를 눌러 보면, 풍속의 계수가 양수로 나옵니다. 바람이 강하면 미세먼지가 씻겨 나갈 것 같은데, 왜 반대로 나올까요? 한국의 봄철에는 황사가 강한 바람과 높은 미세먼지 농도를 동시에 몰고 오는 경우가 많습니다. 즉 계절이라는 숨은 요인이 두 값을 함께 밀어 올렸을 수 있습니다. 회귀 계수의 부호를 그대로 "원인과 결과"로 해석하면 안 되는 이유이며, 상관과 인과가 다르다는 사실을 다중 회귀에서도 잊지 말아야 합니다.
04 · 바이브 코딩 실습

진짜 데이터로, 다중 회귀 앱 만들기

이번에도 AI에게 프롬프트로 부탁해 스트림릿(Streamlit) 앱을 만들어 봅니다. 위 실험에서 쓴 것과 같은 서울 기온·풍속·미세먼지 데이터를 사용합니다.

  1. ① 샘플 프롬프트 — 그대로 붙여 넣기
    ① AI에게 보낼 프롬프트
    "서울 미세먼지 다중 회귀 앱"이라는 스트림릿 앱을 파일 하나로 만들어 줘.
아래 주소의 CSV 파일을 읽어서 사용해:
https://raw.githubusercontent.com/keep-growing-park/ds-data-modeling/main/dataset/seoul_air_quality_2015_2024.csv
이 파일의 열 이름은 year_month, avg_temp_c, avg_wind_speed_ms, pm10_ug_m3이야.

avg_temp_c와 avg_wind_speed_ms 두 개를 독립 변수로,
pm10_ug_m3을 종속 변수로 하는 다중 회귀 모델을 만들어 줘.
두 독립 변수 각각의 회귀 계수와 절편을 화면에 보여 줘.
그리고 이 모델이 예측한 값과 실제 값을 비교하는 산점도를 그려 줘.
그래프는 plotly로.

사용자가 기온과 풍속 값을 각각 슬라이더로 입력하면
그 조건에서 예상되는 미세먼지 농도가 크게 표시되게 해 줘.

필요한 라이브러리 목록도 파일로 따로 줘. 버전 숫자는 빼고 이름만.
    선생님 확인용 예시 코드

    main.py와 requirements.txt, 두 파일로 저장합니다.

    main.py
    import streamlit as st
import pandas as pd
import plotly.express as px
from sklearn.linear_model import LinearRegression

DATA_URL = "https://raw.githubusercontent.com/keep-growing-park/ds-data-modeling/main/dataset/seoul_air_quality_2015_2024.csv"

st.title("서울 미세먼지 다중 회귀 앱")

df = pd.read_csv(DATA_URL)
X = df[["avg_temp_c", "avg_wind_speed_ms"]]
y = df["pm10_ug_m3"]

model = LinearRegression()
model.fit(X, y)
pred = model.predict(X)

c1, c2 = st.columns(2)
c1.metric("기온 계수", f"{model.coef_[0]:.3f}")
c2.metric("풍속 계수", f"{model.coef_[1]:.3f}")
st.caption(f"절편: {model.intercept_:.2f}")

fig = px.scatter(x=y, y=pred, labels={"x": "실제 PM10", "y": "예측 PM10"})
fig.add_shape(type="line", x0=y.min(), y0=y.min(), x1=y.max(), y1=y.max())
st.plotly_chart(fig, width="stretch")

temp = st.slider("기온(℃)", -10.0, 35.0, 15.0)
wind = st.slider("풍속(m/s)", 0.0, 5.0, 2.2)
guess = model.predict([[temp, wind]])[0]
st.metric("예상 PM10 농도", f"{guess:.1f} ㎍/㎥")

  3. ③ 개선 프롬프트 — 계절도 함께 고려하기
    ③ 개선 프롬프트
    year_month 열의 앞 4자리는 연도, 뒤 2자리는 월이야.
월이 3, 4, 5월이면 "봄", 아니면 "봄 아님"으로 구분하는
열을 새로 만들어서 산점도에 색깔로 구분해서 보여 줘.
봄철과 봄이 아닌 계절의 평균 미세먼지 농도도

05 · 정리

핵심 정리

01

다중 선형 회귀는 독립 변수를 두 개 이상 사용해 종속 변수를 예측하며, 독립 변수가 2개면 예측값은 하나의 평면으로 나타난다.

02

회귀 계수의 부호가 항상 직관과 일치하지는 않는다. 계절처럼 숨어 있는 다른 요인 때문일 수 있으므로, 상관과 인과는 구분해서 해석해야 한다.

03

고차항을 새로운 독립 변수로 보면, 다항 회귀도 다중 회귀와 같은 방식으로 계산할 수 있다.
